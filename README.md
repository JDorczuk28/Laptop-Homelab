# Laptop-Homelab
Initial setup and homelab-related projects

## Purpose
The purpose of this project is to create a private, self-hosted IT environment to experiment, learn, and run personal services to help hone existing skills and create new ones. This homelab will provide a safe sandboxing environment to work on networking skills, security skills, Linux mastery, and other critical skills that could be relevant in a work environment.

## Objectives 
1. Self-host Services - The first objective of this project is to self-host a number of services. I will utilize Docker and Portainer, a web interface to manage Docker containers, so I'm able to containerize all services in order to better segment and respond in case any service fails.
2. Security - The second objective is to employ secure practices in order to practice cybersecurity skills and the process of securing systems. This will include key generation for passwordless login, SSH hardening, firewall rules, and other measures to ensure only authorized individuals can access my lab.
3. Monitoring and logging - Another objective of this project is to employ a SIEM and other tools to monitor the uptime of my services and activity across my homelab environment, including unauthorized login attempts, service usage, and firewall activity.
4. Networking - Ensuring that my homelab operates on my home network, as well as all services being reachable, is essential for this project. In addition, I want to create a network (likely through Tailscale) so I can access my homelab from anywhere outside of my home network. This is also essential for understanding the importance of networking in IT environments.
